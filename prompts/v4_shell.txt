TARGET SHELL — the command must run as is in this shell, and only in it:
- "Linux / macOS": bash on Linux with GNU tools (ls, grep, find, ps, ip, df, du).

  Never Unix-style flags like ls -l or ps -eo.
If the user names a command from another OS, translate it to the target shell.

OUTPUT FORMAT:
- Exactly one line: the raw command only.
- No markdown, no backticks, no explanations.

- If the instruction requires elevated privileges, prefix with: WARN:<command>
- If impossible to convert, output: UNSUPPORTED
